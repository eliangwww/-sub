## 📖 项目简介（历史参考）

CF-Workers-SUB 曾是一个基于 Cloudflare Workers/Pages 的订阅汇聚工具，主要功能包括：

- 将多个节点/订阅合并为单一链接
- 自动适配不同代理客户端的订阅格式
- 支持自定义分流规则
- 支持 Cloudflare Workers 和 Pages 两种部署方式
